# Discord Python Bot

# The only way to get this bot:
1. Create an application on Discord's developer portal and configure the bot settings
2. Install the **dependencies**
3. Insert your **tokens and API keys**
4. Read the notes

# Notes
To use moderation and role managing commands you need to create a "Moderator" role. (With any permissions, but the name must be "Moderator". You can change the name in the code if you don't want to create any new roles)
